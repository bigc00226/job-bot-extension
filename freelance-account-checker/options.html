Slack connection

Freelance Account Checker and Job Finder connect to Slack with one Slack user token (starts with xoxp-), set up right here. Do steps 1–3 once per workspace; in another browser or on another PC, only step 2, with the same token. It is stored only in this browser.

1. Create the Slack app (once)

Create the Slack app My Slack apps

Slack opens with the app (its name and scopes) already filled in; sign in to Slack in this browser if asked. Pick the workspace → Next → Create, then on OAuth & Permissions press Install to Workspace → Allow and copy the User OAuth Token. Already made the app? Don't make a second one: copy its token from My Slack apps → the app → OAuth & Permissions.

setup/slack-app-manifest.json couldn't be read, so Slack opens without the app filled in: paste that file's contents as the app manifest.

2. Paste the token

3. Create the channels (once)

Creates (or unarchives) and joins . Channels that already exist are left as they are, so it's safe to press again.

Options

Job Finder: paste the same token in Job Finder → Settings → Slack → Save & test.

While a token is saved, #accounts is also watched: an ACCOUNT REQUEST message (Job Finder → Accounts → Request accounts) makes this browser check its sign-ins again and post every account it finds there.

Alerts (#alert)

The Coconala, CrowdWorks and Lancers accounts signed in here are looked at afresh at the interval below, with no window or tab opened: the site's page is loaded in this extension's hidden page with this browser's sign-in, and only the numbers on its header's ✉ message and ☑ transaction / やることリスト buttons are read (on CrowdWorks the 🔔 お知らせ, where contracts and 仮払い appear). When a number goes up, a new message or transaction is announced in #alert with the account that received it (the channel is created if it's missing). On Coconala, https://coconala.com/message is opened as well, and each conversation showing an unread number is posted with its sender, time and message as the list shows them (conversations aren't opened, so nothing is marked read); Job Finder pops it up and lists it under the account. A badge already showing when alerts start is announced once.

DMs

While a token is saved, Job Finder's DM requests to an account signed in here are also carried out (send a message to a job's client, then post DM Success / DM Failure in the request's thread): CrowdWorks DMs come in #crowdworks (the job page is loaded and its 相談 box used), Coconala DMs in #coconala (the client's page is loaded, メッセージを送る pressed, and the message sent from the message window), Lancers and Workana DMs in #messages. About 2 seconds pass before each input and click, and about 3 seconds after each click — for proposals too. Messages and transactions on the sites are never read.

Lancers packages

While a token is saved, Job Finder's PACKAGE REQUEST in #package (made if missing) for the Lancers account signed in here is carried out: https://www.lancers.jp/myplan/add is opened in a minimized window, 手動でパッケージを作成する pressed, and every step filled in from what Job Finder sent (text about 1 second apart, selections 0.3 seconds apart), pressing 次へ after each; the images, video, audio and PDF are attached last (when the package has any — they're optional). Progress and the result are posted in the request's thread. The package and its files come from Slack, so the token needs the files:read scope (and Job Finder's files:write).

Lancers portfolio items

Job Finder's PORTFOLIO button posts a PORTFOLIO REQUEST to Slack #portfolio (searchable there). The browser signed in to that Lancers account opens myportfolio, presses 新規作成, fills in the form with the cover image and contents, and answers in the request's thread.

Auto-propose (Lancers / Coconala / CrowdWorks)

While on, new messages in #lancers, #coconala and #crowdworks from the sender below are opened as Lancers proposals, Coconala offers or CrowdWorks proposals (by their URL), filled in and submitted automatically, and the result is posted back to the channel. Checked every 5 seconds; orders posted while it is off are ignored.
