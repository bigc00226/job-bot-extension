Slack

Paste the same Slack user token (starts with xoxp-) that is saved in Freelance Account Checker. No token yet? Set Slack up in Freelance Account Checker first (right-click its icon → Options → Slack connection: it creates the Slack app and the channels), then paste its token here. Job Finder reads #accounts with it, posts BID orders to #lancers / #coconala / #crowdworks and watches those channels for the Success / Failure reports. It is stored only in this browser.

Clear Slack channels

Deletes every message (including thread replies) from the ticked channels. You are asked to confirm with the exact count first. Slack only lets a token delete its own messages unless it belongs to a workspace admin. Freelance Account Checker posts the accounts to #accounts again on its next check.

Desktop helper: notifications and the pinned window

Chrome can't put a window above other programs or on every virtual desktop. The small Job Finder Helper for Windows can: with it, new jobs and messages pop up in the top-right corner above every window (without taking the keyboard focus), and the 📌 pinned window shows on every desktop, so it stays in view when you switch desktops. Install it once: in the Job Finder folder, open native and double-click install.cmd; when it asks, paste the ID below. Then reload this page. Without it, notifications open in a small Chrome window.
